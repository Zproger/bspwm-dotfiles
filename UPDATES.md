# Updates

## 2026-09-09

- Исправлены разрывы кадра (screen tearing): включён V-SYNC в конфиге picom, который используется по умолчанию (issue #72).
- Конфиги VSCodium (settings.json, keybindings.json) перенесены в `config/VSCodium/User/`, чтобы они автоматически подтягивались при установке вместе с остальными конфигами.
- Исправлено определение мониторов в `dual_monitors.sh`: имена мониторов теперь определяются динамически вместо жёстко заданных `eDP-1`/`HDMI-1-1`, чтобы рабочие столы не пропадали на другом железе (баг из issue #7 в PR #24).
- Добавлено меню истории буфера обмена на `greenclip` + rofi: хоткей `super + v` (bin/clipboard-menu, автозапуск демона в bspwmrc, пакет добавлен в Builder).
- Исправлено уведомление о заряде батареи (`bin/battery-alert`): вместо жёстко заданного `BAT1` устройство определяется автоматически, иначе на батареях с другим именем (например `BAT0`) уведомления не приходили никогда.
- Исправлен `bin/brightness`: убран вызов несуществующей функции `get_backlight` (падало с ошибкой на `--get` и без аргументов) и опечатка `5-%` → `5%-` в команде уменьшения яркости.
